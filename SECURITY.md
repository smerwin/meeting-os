# Security Policy

## Reporting a vulnerability

Please don't open a public issue for security vulnerabilities. Instead, use
GitHub's private reporting: go to the **Security** tab of this repo → **Report a
vulnerability**. Include:

- A description of the vulnerability and its impact
- Steps to reproduce
- Any relevant logs or PoC code

We'll acknowledge your report and follow up with next steps.

## Scope

This is a personal/open-source project run on Cloudflare Workers. There is no
bug bounty program.
